\# LAN Share - 极简局域网文件互传



一个基于 Vue3 + Fastify 的局域网文件互传工具，支持 Windows、macOS、Android、iOS 互传文件与文本。



\## 特性

\- 极速传输：分片上传（4MB/片），断点续传。

\- 聊天式 UI：文本与文件混合会话流。

\- 局域网直连：无需外网，不经过云端，保护隐私。

\- 多端支持：适配 PC 与移动端浏览器。
